G3Q — AI Modules: Technical Overview

G3Q (Gujarat Gyan Guru Quiz) uses 5 AI modules across question generation, personalization, explanation, imagery, and student support.

1. AI Question Bank Module

One-time process

Model: Gemini Flash 3.6 (Generator, Reviewer)

Source PDFs and authorized sites are extracted into sector-wise text files and embedded before generation. Gemini Flash 3.6 drafts questions one sector at a time; a second Flash 3.6 reviewer either commits approved items to the question bank or sends them to a modifier, which edits to the reviewer’s instructions and re-enters review. This pipeline is offline relative to quiz play — it fills the bank, it does not run at session start.

Registration attributes go to the backend, which extracts 50 in-scope bank questions (district, taluka, caste, stream, and related filters). Gemini 3.5 Flash then selects and personalizes a 15-question session from that pool — and may attach interactive elements — so each quiz start is both bank-constrained and student-specific.

3. Explanation Generator Module

Runs per question

Model: Gemini 3.5 Flash Lite

flowchart LR
    m3A[Question + Options + Correct Answer] --> m3C["Explainer Model — Gemini 3.5 Flash Lite"]
    m3B[Student Details] --> m3C
    m3C --> m3D["Short Explanation 
 Pre-generated on question-page load to minimize latency"]
    classDef input fill:#d4e7e2,stroke:#2c5f56,stroke-width:1.2px,color:#1b1b1b
    classDef model fill:#d6deef,stroke:#2e3f68,stroke-width:1.2px,color:#1b1b1b
    classDef output fill:#ebd4c9,stroke:#7a402c,stroke-width:1.2px,color:#1b1b1b
    class m3A,m3B input
    class m3C model
    class m3D output

The explainer receives the stem, options, correct answer, and student profile, and writes a short explanation. Generation is triggered on question-page load — not after the student answers — so the copy is already in hand when the result UI needs it, keeping latency off the critical path.

4. Background Image Generation Module

One-time process

Models: FLUX.1 Schnell · Gemini 3 Flash Lite

    class m4B process

    class m4E output

For each question, the sector and category are passed to a style router, which assigns each of the 6 image styles to whichever model renders it best — FLUX.1 Schnell or Gemini 3 Flash Lite. All 6 style variants are generated once per question and stored against that question in the database, so at quiz time the platform simply fetches the pre-generated image for the quiz's chosen style rather than generating anything live.

5. G3Q AI Assistant Module

Runs per student query

Model: Gemini Flash 3.1 Lite

flowchart LR
    m5A[Student Query] --> m5D["Assistant Model — Gemini Flash 3.1 Lite"]
    m5B[Student User Info] --> m5D
    m5D -->|Browses only| m5E["G3Q Official Site & 
 Other Authorized Sources"]
    m5E --> m5D
    m5D --> m5F[Personalized Answer to Student]
    classDef input fill:#d4e7e2,stroke:#2c5f56,stroke-width:1.2px,color:#1b1b1b
    classDef model fill:#d6deef,stroke:#2e3f68,stroke-width:1.2px,color:#1b1b1b
    classDef output fill:#ebd4c9,stroke:#7a402c,stroke-width:1.2px,color:#1b1b1b
    class m5A,m5B,m5E input
    class m5D model
    class m5F output

The assistant takes the student query and user info, then may browse only the G3Q official site and other authorized sources before answering. Grounding is closed-world relative to those sources; the returned answer is personalized to the student, not a general web search.
